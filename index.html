Task Manager Web Application

Full-stack project

A full-stack task manager with secure, per-user access. The FastAPI backend provides 14 REST endpoints for registration, login, tasks, profiles and health checks, protected by JWT authentication and bcrypt password hashing, with pagination and filtering. Tasks carry priorities and deadlines, and each user gets a personalized motivation message. 17 automated tests cover authentication, task operations and isolation between users. The backend runs on Render and the plain HTML, CSS and JavaScript frontend on Vercel, from a 32-file repository that includes Docker configuration.

Built with Python, FastAPI, SQLAlchemy, SQLite and JWT.

Healthcare Assistant with RAG and LangGraph

AI project

A health assistant that answers only from trusted sources. Open web searches on topics such as malaria can return unverified sites, so a LangGraph router agent sends each question either to a RAG tool, which searches an uploaded malaria PDF stored in a Chroma vector database, or to a web search restricted to the WHO website. The answer is summarized with a Groq-hosted model and states whether it came from the PDF or WHO. Questions outside these sources are declined.

Built with LangGraph, Chroma, Groq, Tavily and Streamlit.

Student Academic Q&A using Retrieval-Augmented Generation

AI project

A Retrieval-Augmented Generation assistant for course material. PDFs and YouTube lecture videos are ingested together: video audio is transcribed with Faster-Whisper, the text is split into overlapping chunks, embedded with a multilingual E5 model and stored in a Chroma vector database. The most relevant chunks go to a Llama model on Groq, and every answer cites its source document and page. If the material does not contain the answer, the assistant says it has no information instead of guessing.

Built with Python, Chroma, Faster-Whisper, Groq and Llama.

GIS-Based Power Infrastructure Monitoring and Maintenance

Final-year engineering project

A final-year project completed by a team of three under the guidance of TNEB, and used by TNEB. TNEB's engineering drawings of the underground cable network were converted into structured digital map layers in QGIS, covering substations, feeder routes and cable paths. Mapped routes include 230 kV and 110 kV lines. A Python tool takes substation, feeder and fault-distance inputs and calculates the fault position, replacing a slow manual process. The work shortens fault location time and supports data-driven monitoring and maintenance.

Built with Python and QGIS.

Personalized Letter Writing MCP

AI project

An MCP server built with Python and FastMCP that lets AI assistants such as Claude write personalized letters. Users share their thoughts, choose English, Tamil or Tanglish, a tone and up to three visual themes, then pick one of six formats, from plain text to handwritten-style and scrapbook letters, or describe a custom one. The server prepares structured instructions and writing guidelines, and the connected AI produces the finished letter. It also runs as a skill in Claude Desktop.

Built with Python, FastMCP and uv.
